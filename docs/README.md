# Exhale developer documentation

The developer documentation is split by purpose:

- [`architecture.md`](architecture.md) records durable component boundaries,
  ownership, and data flow.
- [`code-overview.md`](code-overview.md) is the file-by-file guide to the
  hand-written source.
- [`development.md`](development.md) defines coding, documentation, testing,
  compatibility, and release conventions.

Keep these documents descriptive of the current code. Plans and temporary
implementation notes do not belong here.
